# Goma Framework
A simple, bare-bones game framework made for personal use in C++ with SDL3.

## Purpose
I made this to get familiar with C++, and to have a basis for my future games, it gives me full control and understanding over what I need in a game framework without extra unnecessary features (or conversly, extra features I tend to have to integrate myself in other frameworks). It's mostly a wrapper around SDL3 to simplify development.

## Usage
Refer to [the example file](https://github.com/SpaceSealLover/GomaFramework/blob/master/example.cpp) for reference on how your main file should look. The header should also be self explanatory.
